# My Journey in Learning JS

- **Start Date:** Last week of 2025
- **End Date:** April 2026
- **Learning Source:** Elzero

My journey with JavaScript was a truly beautiful experience where I learned a great deal about logic and code organization. It was certainly a challenging journey—I faced procrastination at times, but I kept going and refused to stop.

During this period, I aspired to build my own business using JavaScript. Although it didn't succeed, I persevered and completed my learning journey to the end. Afterward, I evaluated the situation and decided to pivot and transition to a different specialty.

Overall, it was a highly successful starting point. When I began, I knew absolutely nothing about programming. Through JavaScript, I learned everything from writing code to organizing and cleaning it, covering almost all the core aspects of the language.

Of course, there were challenges along the way, but I was able to overcome them and keep moving forward. I look forward to making much more progress in the future.
